## 🚀 Featured Projects

### 🧠 Package Hallucination Detection

An end-to-end machine learning system for detecting hallucinated and potentially deceptive Python package recommendations generated by Large Language Models.

* Engineered features using package-name characteristics and PyPI metadata
* Built and evaluated Random Forest classifiers
* Developed an import-name reconciliation layer for cases such as `cv2 → opencv-python`
* Integrated detection into a LangGraph retry/fallback agent
* Built a Streamlit application for interactive inference

**Tech Stack:** Python · Scikit-learn · Pandas · NumPy · Random Forest · LangGraph · Streamlit

📄 **Research:** [Names Can Hurt: Spotting Slopsquatting Risks Caused by Package Name Hallucinations in Local Coding LLMs](https://arxiv.org/abs/2608.23897)
