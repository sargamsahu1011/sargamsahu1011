# 🤖 AI Research

## Package Hallucination & Slopsquatting Detection

A research-oriented machine learning system for detecting hallucinated and potentially deceptive Python package recommendations generated by Large Language Models.

### Pipeline

```text
                 ┌──────────────────┐
                 │      LLMs         │
                 └────────┬─────────┘
                          ↓
              Package Recommendation
                          ↓
                ┌──────────────────┐
                │  Feature Engine  │
                └────────┬─────────┘
                         ↓
          Package Name + PyPI Metadata
                         ↓
                ┌──────────────────┐
                │ Random Forest ML │
                └────────┬─────────┘
                         ↓
               Risk Classification
                         ↓
                ┌──────────────────┐
                │ Import Reconciler│
                └────────┬─────────┘
                         ↓
                ┌──────────────────┐
                │ LangGraph Agent  │
                └──────────────────┘
```

### Key Work

* Engineered **10 features** from package-name characteristics and PyPI metadata
* Built Random Forest classifiers
* Evaluated multiple open-source LLMs
* Developed an import-name reconciliation layer
* Resolved cases such as:

```text
import cv2
      ↓
pip install opencv-python
```

* Integrated the detection system with LangGraph retry/fallback logic
* Built a Streamlit inference application
* Coordinated a **24-person user study**

### Research Result

```text
                               │
                               ↓
28.7%  ────────────────        │
                               │
                         Reduced failure
```
